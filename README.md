# MedConsult 2 — текстовый станок протокола

PWA. Vite + React + Tailwind. Собирает текст приёма чипами и полями, копирует блоки в буфер для Медлока или Word. Работает офлайн, данные в `localStorage`.

Живая копия: **https://argtiq.github.io/medconsult/**

## Установить как приложение

1. Откройте https://argtiq.github.io/medconsult/ в Chrome / Edge / Safari.
2. **Windows / Android:** в адресной строке — «Установить», либо меню → «Установить приложение» / «Добавить на главный экран».
3. **iPhone:** Поделиться → На экран «Домой».

После установки открывается без браузерной рамки, работает офлайн.

## Что умеет

- Старт всегда с **Протокола**. Страница Старт — полка, не дверь.
- Вид приёма (первичный / повторный) и **+ обследование** на одной линейке.
- Обследования — кнопки, не чеклист. Несколько результатов (сегодня + предыдущее УЗИ / несколько ОАМ).
- Поля с референсом сразу под цифрой. Объём простаты считается сам: Д×Ш×В×0,52.
- Справа — то, что уйдёт в Медлок, в клиническом порядке. Пустые блоки не копируются. Шапка — спойлер, копируется отдельно.
- Крестик удаления только в сборке.
- Словарь жалоб глобальный + сортировка по МКБ. Локальный статус — пакеты по коду.
- Клинрек: блок или модалка (настройки). Сценарии опциональны.
- История визитов, повтор прошлого сеанса, Ctrl+K вставка.
- Экспорт / импорт JSON. Горячие клавиши Windows в настройках.
- Адаптив: на телефоне вкладки «Сборка / В Медлок» и нижнее меню.

Не перенесены из старого репозитория (можно вернуть позже): шифрование clinical-namespace, живой Supabase-синк, полный редактор лекарств/шаблонов, печать PDF, голосовой ввод.

## Запуск локально

```bash
npm install
npm run dev
```

## GitHub Pages

В `vite.config.js` стоит `base: "/medconsult/"`. Пуш в `main` сам собирает и публикует через Actions.

Если репозиторий не `ARGtiq/medconsult`, поправьте `homepage` в `package.json` и `base`.

## Клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+K | Поиск и вставка |
| Ctrl+Enter | Копировать всё без шапки и пустых |
| Ctrl+Shift+C | Активный блок |
| Ctrl+Shift+H | Шапка |
| Ctrl+Z | Отменить AI |
| Esc | Закрыть меню |
