# MedConsult — PWA для протокола медицинской консультации

React + Vite. Личный/командный инструмент для ведения приёма (жалобы, анамнез,
диагноз, обследования, назначения), с клиническими рекомендациями, базой
лекарств, редактируемым справочником исследований, печатью протокола и
опциональной синхронизацией через Supabase.

## Основные возможности

**Приём**
- Конструктор жалоб/анамнеза чипами: категории открытыми блоками (не спойлерами),
  drag-and-drop порядка, голосовой ввод, длительность анамнеза (число/«много» +
  единица с правильным склонением)
- Аккордеон секций визита — свёрнуты все, кроме активной; заполненные показываются
  текстом до клика
- Автоподсказки препаратов по жалобам и по диагнозу (обучается на твоей практике)
- Мгновенная локальная проверка аллергии (прямая, по группе — включая название
  группы целиком, не только конкретный препарат, — перекрёстная реактивность)
- "Проверить несовместимость (AI)" учитывает и уже принимаемые пациентом лекарства
- Панель клинических рекомендаций по коду МКБ-10 в диагнозе — блок прямо на
  странице приёма (по умолчанию) или модальное окно (переключается в Настройках);
  все вставки — по клику на чип, без автоподстановки
- Живые теги (формулировка диагноза "помнит", из какой рекомендации вставлена)
- Дедупликация визитов: сохранение той же датой обновляет визит, не плодит копии;
  отдельная кнопка "Сохранить как новый визит"
- Автосохранение черновика, пресеты, шаблон по умолчанию
- Ctrl/Cmd+S — сохранить визит с клавиатуры

**Протокол исследований** (отдельный тип шаблона)
- Отметил галочкой исследование — можно заполнить как обычным текстом, так и
  отдельными полями (Tab между ними), переключение между способами не теряет
  данные
- У каждого исследования — шпаргалка с нормами/референсными значениями по клику
- Список исследований редактируется в Справочнике, общий для всех визитов
- Встроены: урофлоуметрия, УЗИ почек/мочевого пузыря, ТРУЗИ, УЗИ мошонки,
  ТА УЗИ простаты, допплерография полового члена, ОАМ, ОАК

**Справочник**
- Шаблоны консультаций — секции получают явную **роль** (Диагноз/Жалобы/
  Рекомендации), а не угадываются по id
- Клинические рекомендации: сценарии терапии по тяжести/пути введения с дозами,
  AI-экстракция из текста (формат reclin.ru и подобных)
- База лекарств: дозировка, кратность, длительность курса, торговые названия
  (редактируются прямо на карточке назначения), МКБ-коды, мониторинг
- Группы лекарств: побочки/противопоказания/перекрёстная аллергия, свои связки
- Исследования: полноценный редактор (название, категория, шаблон текста,
  поля с нормами, шпаргалка) — свои переопределяют встроенные по ключу
- Печать: свои шаблоны шапки/подписи документа для печати протокола

**Пациенты**
- Карточки, история визитов, поиск по всем визитам сразу (диагноз/жалобы/препараты)
- Опциональное шифрование паролем (Настройки → Защита данных пациентов)
- Лекарства, введённые как аллергия или как принимаемые сейчас, автоматически
  регистрируются в базе лекарств
- Удаление — мгновенное, с кнопкой "Отменить" (tombstone, не физическое стирание)

**AI** (OpenRouter или Google AI Studio напрямую, ключ вводится в приложении)
- Проверка взаимодействий (включая принимаемые лекарства), перекрёстной аллергии,
  аналогов, подсказка диагноза, "причесать" текст протокола
- Экстракция данных из текста инструкции/клинрека
- Кнопки показывают состояние выполнения, не только по факту завершения

**Печать и PDF**
- Кнопка "🖨 Печать / PDF" в превью протокола — через стандартный диалог печати
  браузера, с настраиваемым летерхедом (клиника/врач/контакты) и подписью

**Поиск и навигация**
- Глобальный поиск (Ctrl/Cmd+K или значок 🔍) — сразу по пациентам, визитам,
  клинрекам, лекарствам
- Главная — черновики, последние визиты, пациенты, отдельные блоки по каждому
  разделу справочника с последними записями, чек-лист первых шагов, напоминание
  о бэкапе

**Интерфейс**
- Единая система уведомлений (toast) вместо разрозненных индикаторов
- Esc закрывает любую модалку, автофокус на первое поле, видимая подсветка
  обязательных полей при попытке сохранить пустыми
- Адаптивная ширина модалок; формы с данными не закрываются кликом мимо
  (только явной кнопкой)

**Данные и синхронизация**
- Хранилище разложено по неймспейсам (clinical/reference/workspace/system)
- Supabase: magic link вход, инкрементальная синхронизация визитов и пациентов
  (только изменённое, построчно, отдельные таблицы), блочная — для справочников,
  автосинк в фоне после сохранения
- Выборочный экспорт/импорт по разделам

## Запуск локально

```bash
npm install
npm run dev
```

## Деплой на GitHub Pages

Смотри `vite.config.js` → `base` должен совпадать с названием репозитория.
Собранный `dist/` пушится в ветку `gh-pages` (см. `.github/workflows/deploy.yml`,
если настроен Actions) или вручную через `npm run deploy`.

## Подключение Supabase (опционально)

Без Supabase приложение полностью работает офлайн на localStorage одного браузера.
Чтобы включить синхронизацию между устройствами:

1. Создай проект на supabase.com
2. Выполни SQL из Настройки → Общие → Supabase → "SQL для настройки таблиц"
   (там всегда актуальная версия схемы: неймспейсы + построчный синк визитов/
   пациентов + зашифрованные AI-ключи)
3. Скопируй Project URL и anon key (Project Settings → API) → вставь в
   Настройки → Общие → Supabase в самом приложении
4. Войди по email (magic link)
5. "Проверить соединение" должно показать ✓

Если при повторном выполнении SQL встречается ошибка "policy ... already exists" —
это нормально при повторном запуске; можно убрать уже созданные блоки `create policy`
или оборачивать их в `DO $$ IF NOT EXISTS ... $$` (для `insert`-политик — только
`WITH CHECK`, без `USING`).

## Структура проекта

```
src/
  App.jsx                 — навигация, глобальный поиск, автосинк, точки входа страниц
  AppRoot.jsx              — гейт разблокировки (если включено шифрование пациентов)
  lib/
    store.js               — вся работа с данными, неймспейсы, миграции, tombstones
    clinicalLock.js         — шифрование неймспейса clinical
    supabaseSync.js          — push/pull (блочный и инкрементальный)
    autoSync.js               — фоновая отправка изменений после сохранения
    openrouter.js              — AI-вызовы
    toast.js                    — система уведомлений
    print.js                     — печать/PDF через скрытый iframe
    uiPrefs.js                    — мелкие настройки интерфейса (localStorage)
    useEscapeToClose.js            — хук закрытия модалки по Esc
    duration.js, keyVault.js, evidencePrompt.js — утилиты
  data/
    drugSafety.js            — группы лекарств, перекрёстная реактивность
    mkb10.js                  — справочник МКБ-10
    studyProtocols.js          — встроенные исследования (шаблоны, поля, нормы)
  components/               — вся остальная логика по функциональным зонам
```

## Известные ограничения

- Справочники (шаблоны/клинреки/лекарства/группы/исследования/печать)
  синхронизируются блоком целиком, не построчно — при одновременном
  редактировании на двух устройствах может потеряться часть правок
  (last-write-wins на весь блок)
- Автосинк работает только для визитов и пациентов, не для справочников
- Нет полноценного слияния конфликтующих полей — при конфликте побеждает
  более свежая по времени версия записи целиком
- Печать — только через диалог браузера ("Сохранить как PDF" в списке
  принтеров), отдельного генератора PDF-файла нет
